# Система управления успеваемостью "Teacher Dashboard"

### Общее описание

Система представляет собой интерактивный веб-интерфейс для преподавателей, предназначенный для оперативного мониторинга успеваемости студентов и управления учебными задачами. Ключевым элементом является "Умная таблица", позволяющая фильтровать список студентов по множеству параметров одновременно (мультипоиск через чипсы) и назначать задания без перехода на другие страницы.

---

### Основной положительный сценарий (Мультипоиск и фильтрация студентов)

1. Преподаватель открывает страницу "Мои студенты".
2. В строке поиска (над таблицей) преподаватель начинает вводить критерий (например, название группы "ПИ-21" или фамилию).
3. Система предлагает варианты автодополнения.
4. Преподаватель выбирает нужный вариант или нажимает Enter.
5. Введенный критерий превращается в интерактивный "чипс" (тег с крестиком для удаления) внутри строки поиска.
6. Таблица мгновенно перестраивается, отображая только записи, соответствующие **всем** активным чипсам (логическое "И").
7. Преподаватель добавляет второй чипс (например, выбирает фильтр "Должники" или вводит название конкретного предмета).
8. Система сужает поиск, показывая студентов группы "ПИ-21", у которых есть долги.

#### Альтернативные сценарии

* **Ничего не найдено (на шаге 6/8):**
* Система отображает пустую таблицу с сообщением "По заданным критериям студентов не найдено".
* Система предлагает удалить последний добавленный чипс для расширения поиска.


* **Удаление фильтра:**
* Преподаватель нажимает на крестик на одном из чипсов (например, убирает "ПИ-21").
* Таблица автоматически обновляется, показывая "Должников" по всем группам.

### Пользовательские истории

### 1. Глубокая фильтрация и поиск (Мультипоиск через чипсы)

**Я, как преподаватель, хочу находить студентов, комбинируя разные параметры (группа + статус + фамилия), чтобы быстро выделить нужный сегмент для работы.**

* **Основной сценарий:**
1. Преподаватель кликает в строку поиска над таблицей.
2. Выбирает из выпадающего списка быстрых фильтров чипс "Группа: ПИ-21".
3. В строке поиска появляется чипс (тег). Таблица фильтруется.
4. Преподаватель вводит вручную "Иванов" и нажимает Enter.
5. Добавляется второй чипс "Иванов".
6. В таблице остается единственная строка: студент Иванов из группы ПИ-21.


* **Альтернативные сценарии:**
* *Ничего не найдено:* Система показывает сообщение "По запросу [Группа: ПИ-21] + [Петров] ничего не найдено" и предлагает сбросить последний фильтр.
* *Удаление фильтра:* Преподаватель нажимает крестик на чипсе "Группа: ПИ-21", и таблица показывает всех студентов с фамилией Иванов во всех группах.


### 2. Визуальный мониторинг успеваемости

**Я, как преподаватель, хочу видеть прогресс студента прямо в списке (в виде шкалы или цветного индикатора), чтобы мгновенно выявлять отстающих.**

* **Основной сценарий:**
1. Преподаватель просматривает колонку "Выполненные задания".
2. Система отображает данные не просто числом, а визуально: недоделанные задания подсвечиваются желтым, выполненные - зеленым
3. Преподаватель нажимает на заголовок столбца "Выполненные задания".
4. Таблица сортируется от меньшего к большему.
5. Студенты с наименьшим количеством сданных работ оказываются вверху списка для особого внимания.


* **Альтернативные сценарии:**
* *Сортировка по имени:* Преподаватель кликает на заголовок "Имя", чтобы вернуть алфавитный порядок.



### 3. Быстрое добавление задания (Персонально)

**Я, как преподаватель, хочу выдать индивидуальное задание студенту прямо из общего списка, не переходя на отдельную страницу создания задачи.**

* **Основной сценарий:**
1. В строке конкретного студента (в колонке "Действия" или "Добавить задание") преподаватель нажимает кнопку "+".
2. Открывается модальное окно. Поля "Студент" и "Группа" уже предзаполнены и заблокированы.
3. Преподаватель вводит тему задания (например, "1").
4. Нажимает чек-бокс "Выполнено".
5. Нажимает "Назначить".
6. Счетчик заданий у студента мгновенно обновляется (было 10, стало 11), появляется всплывающее уведомление "Задание назначено".


* **Альтернативные сценарии:**
* *Отмена действия:* Преподаватель нажимает "Отмена" или кликает вне всплывающего окна — окно закрывается, данные не сохраняются.



### 4. Массовое добавление задания (Контекстное действие)

**Я, как преподаватель, хочу быстро выдавать задания, без нужды несколько раз менять поиск. **

* **Основной сценарий:**
1. Преподаватель настраивает фильтры через чипсы (например, выбрал только чипс "Группа: ИС-32").
2. В шапке таблицы активируется кнопка "Добавить задание для всех найденных (25)".
3. Преподаватель нажимает эту кнопку.
4. В модальном окне указано: "Получатели: 25 студентов (Группа ИС-32)".
5. После заполнения деталей и нажатия "Отправить", задание рассылается всем 25 студентам.


* **Альтернативные сценарии:**
* *Смешанный фильтр:* Преподаватель выбрал чипсы "Группа: ИС-32" и "Должники". Система предлагает назначить доп. задание только должникам этой группы.



### 5. Определение следующего задания 

**Я, как преподаватель, подготавливаясь к занятию хочу знать, какое задание будут выполнять дети во время урока. **

* **Основной сценарий:**
1. Преподаватель настраивает фильтры и выводит детей, которые должны появиться у него на занятии.
2. В строке "Выполненные задания" сортировка идёт по времени сдачи, поэтому можно посмотреть, что ученик делал последним.
3. При нажатии на кнопку "Добавить задание" всплывает окно, где выведены только невыполенные задания и ничего больше.
4. При нажатии на кнопку "Добавить" задание переносится в "Выполненные задания".
5. Если ранее такое же задание было невыполнено - оно становится серого цвета.

* **Альтернативные сценарии:**
* *Отмена задания:* Если получилось так, что преподаватель добавил не то задание - его можно удалить в течение 24 часов. Админ может удалять задания за любой промежуток времени и добавлять также на любую дату.
